# mome (모메)

메모장을 살짝 비튼 Windows 11용 텍스트 편집기. Rust + egui/eframe로 작성했습니다.

- 기본 기능: 새로 만들기, 새 창, 열기, 저장, 다른 이름으로 저장, 최근에 연 파일, 페이지 설정, 인쇄,
  실행 취소/다시 실행, 잘라내기/복사/붙여넣기, 찾기/바꾸기, 줄로 이동, 모두 선택, 시간/날짜, 자동 줄 바꿈, 글꼴, 확대/축소
- **다크 모드**: 메뉴 모음 오른쪽 끝의 달/해 버튼 하나로 전환 (제목 표시줄까지 함께 바뀜)
- **Markdown·JSON·캔버스 파일**: 열기·저장 창에서 `*.txt`, `*.md`, `*.json`, `*.canvas`를 함께 보여 줍니다.
- **읽기 모드 (Markdown·옵시디언 캔버스)**: `.md`·`.canvas` 파일을 열면 메뉴 모음 오른쪽에 `편집 | 읽기` 전환 단추가 나타납니다
  (`Ctrl+E`, `보기 > 읽기 모드`).
  - **Markdown**: 제목, 목록, 할 일 목록, 표, 인용, 코드 블록(색 강조), 링크, 그림을 서식대로 보여 줍니다.
    옵시디언 문법도 읽습니다: `[[노트]]`·`[[노트|별칭]]` 링크, `![[그림.png]]` 그림 넣기, `> [!note] 제목` 콜아웃(한국어 이름표),
    `%%주석%%`(숨김), 맨 앞 속성(`---` 블록).
  - **링크**: `[[노트]]`나 `다른 노트.md` 링크를 누르면 그 노트를 이 창에서 엽니다(`Ctrl+클릭`·가운데 단추는 새 창).
    노트는 옵시디언처럼 같은 폴더, 보관소(`.obsidian` 폴더가 있는 곳) 맨 위, 보관소 전체 순서로 찾습니다.
    웹 주소는 브라우저로, 그림·PDF·소리·동영상은 Windows 기본 프로그램으로 엽니다.
    실행될 수 있는 파일(.exe, .bat, 바로 가기 등)은 링크로 열지 않고 탐색기에서 위치만 보여 주며,
    다른 컴퓨터(네트워크 경로)를 가리키는 링크·그림은 문서가 같은 공유 폴더에 있을 때만 읽습니다.
  - **캔버스**: 카드(글·노트 파일·그림·웹 링크), 그룹, 연결선(화살표·이름표·색)을 옵시디언 캔버스처럼 그립니다.
    끌어서 이동, `Ctrl+휠`로 확대/축소, 오른쪽 위 `전체 보기`(`Ctrl+0`)로 전체를 맞춥니다.
    노트 카드의 파일 이름을 누르면 그 노트를 엽니다. 캔버스 파일은 처음부터 읽기 모드로 열립니다.
  - 읽기 모드는 보기만 합니다. 찾기·붙여넣기·실행 취소처럼 글을 다루는 명령을 쓰면 편집 모드로 돌아갑니다.
- **찾기·바꾸기 (IntelliJ 방식)**: `Ctrl+F` 찾기, `Ctrl+R` 바꾸기(메모장의 `Ctrl+H`도 됨).
  - 찾을 내용 옆의 `Cc`(대/소문자 구분, `Alt+C`), `W`(단어 단위, `Alt+O`), `.*`(정규식, `Alt+X`)로 찾는 방법을 바꿉니다.
    `Enter`/`Shift+Enter`(또는 `F3`/`Shift+F3`)로 다음/이전 항목으로 갑니다.
  - **정규식**: 앞뒤 살피기(`(?=…)`, `(?<=…)`), 역참조(`\1`), 이름 붙인 그룹(`(?<이름>…)`)까지 씁니다.
    `^`·`$`는 줄마다 맞으며, `.*`에 마우스를 올리면 자주 쓰는 문법이 나옵니다. 식이 틀리면 어디가 틀렸는지 알려 줍니다.
    IntelliJ(Java)처럼 뒤쪽 살피기 안에는 길이가 정해진 식만 쓸 수 있고(`(?<=a|bc)`는 됨, `(?<=x.*)`는 안 됨), `\K`는 지원하지 않습니다.
    빈 문자열 일치도 Java와 같게 처리합니다(`b*`를 `-`로 바꾸면 `abc` → `-a--c-`).
  - **그룹으로 바꾸기**: 바꿀 내용에 `$1`·`$2`(그룹), `${이름}`, `$0`(찾은 전체), `\n`(줄 바꿈), `\t`(탭)을 쓸 수 있고,
    `\u`·`\l`은 다음 한 글자를, `\U … \E`·`\L … \E`는 구간을 대문자/소문자로 바꿉니다. `$`·`\` 자체는 `\$`·`\\`로 씁니다.
    예: `(\d{4})-(\d\d)-(\d\d)` → `$1년 $2월 $3일`, `_(\w)` → `\u$1`(`get_user_name` → `getUserName`)
  - 정규식으로 바꿀 때는 지금 고른 항목 아래에 바뀔 결과를 미리 보여 줍니다.
  - `바꾸기`(`Alt+P`, 바꾸고 다음으로), `모두 바꾸기`(`Alt+A`), `제외`(`Alt+L`, 이 항목은 바꾸지 않고 다음으로 넘어감,
    취소선으로 표시)를 씁니다. 제외한 항목은 `모두 바꾸기`에서도 건너뜁니다.
- **보이지 않는 문자 찾기** (`Ctrl+Shift+I`, `편집 > 보이지 않는 문자 찾기`): 폭 없는 공백(ZWSP), 줄 바꿈 없는 공백(NBSP),
  한글 채움 문자(U+3164), 양방향 텍스트 제어 문자(글자 순서를 뒤집어 보이게 함), 제어 문자, 특수 너비 공백, 소프트 하이픈,
  태그 문자처럼 눈에 안 보이거나 일반 공백과 헷갈리는 문자를 종류별로 세어 보여 줍니다.
  - 본문에는 분홍색으로 표시합니다(폭이 없는 문자는 세로 막대, 폭이 있는 문자는 상자). `보기 > 보이지 않는 문자 표시`로 끌 수 있습니다.
    파일을 열 때 이런 문자가 있으면 상태 표시줄에 알려 줍니다.
  - `이전`/`다음`, 종류별 `찾기`로 하나씩 찾아가고, 체크한 종류를 `선택한 문자 정리`로 한 번에 지우거나 일반 공백·줄 바꿈으로 바꿉니다
    (`Ctrl+Z`로 되돌릴 수 있음).
  - 태그 문자나 연속된 이체자 선택자에 숨겨 둔 글자(AI에 몰래 지시를 넣는 수법 등)는 풀어서 `숨은 글자`로 보여 줍니다.
  - 한국어 글에 흔한 전각 공백(U+3000)은 목록에만 나오고 본문 표시·기본 정리 대상에서는 빠집니다.
    이모지를 잇는 결합자(👨‍👩‍👧)와 이모지 뒤의 모양 선택자(❤️)는 정상 문자로 봅니다.
- **JSON 정리**: `.json` 파일(캔버스 파일의 편집 모드 포함, 또는 `{`·`[`로 시작하는 제목 없는 문서)을 열면 메뉴 모음 오른쪽에 `{ } JSON 정리` 버튼이 나타납니다.
  `서식 > JSON 정리`로도 할 수 있습니다. 공백 2칸으로 들여쓰기만 다시 하고 키 순서·숫자 표기·한글은 그대로 두며,
  `Ctrl+Z`로 되돌릴 수 있습니다. 형식이 틀렸으면 몇 줄 몇 열인지 알려 주고 커서를 그 위치로 옮깁니다.
- **상태 표시줄**: 줄/열, 글자 수(선택한 글자 수), 200자 원고지 매수, 삽입/겹쳐쓰기(`Insert` 키), 확대 비율, 줄 끝 형식, 인코딩
  - 원고지 매수: 20칸 × 10줄 원고지에 한 칸에 한 글자(공백 포함)씩 옮겨 적었을 때의 장 수입니다.
    문단이 끝나거나 줄이 바뀌면 남은 칸도 채운 것으로 보고 다음 줄부터 쓰며, 빈 줄도 한 줄을 차지합니다(문서 끝의 빈 줄은 제외).
    덜 찬 장도 한 장으로 셉니다. 그래서 대화문처럼 줄 바꿈이 많을수록 글자 수 ÷ 200보다 매수가 늘어납니다.
    한글(HWP) 문서 정보의 원고지 매수와 조금 다를 수 있으니 최종 분량은 한글에서 확인하세요.
    창이 좁으면 원고지 매수는 숨기며, 글자 수에 마우스를 올리면 볼 수 있습니다.
- **겹쳐쓰기 모드**: 한글 IME 조합 중에도 글자 단위로 덮어씁니다
- **인코딩**: UTF-8, UTF-8(BOM), UTF-16 LE/BE, ANSI(CP949) 자동 감지·저장, 다른 인코딩으로 다시 열기, 줄 끝(CRLF/LF/CR) 유지·변경
- **임시 저장**: 처음 실행할 때 임시 저장 폴더를 선택합니다. 내용이 변경되었을 때만 기본 10초마다(설정에서 변경 가능)
  새 버전을 하나씩 더 저장하고(이전 버전은 덮어쓰거나 지우지 않음), `파일 > 임시 저장 기록`에서 원하는 버전으로
  되돌릴 수 있습니다. 보관 기간(최대 30일)이 지난 버전만 자동으로 삭제합니다.
- **원본 파일 자동 저장**: `파일 > 원본 파일에도 자동 저장`을 켜면 파일로 저장한 문서는 원본 파일에도 저장합니다(기본 꺼짐).
- **안전한 저장**: 임시 파일에 먼저 쓴 뒤 원본과 바꾸므로, 저장 중 전원이 꺼져도 원본 파일이 잘리지 않습니다.
  읽지 못한 글자(�)가 있는 파일을 원본에 덮어쓸 때는 먼저 확인합니다.
- **Windows 종료 후 복원**: mome를 켜 둔 채 Windows가 꺼지면, 다음 로그인 때 mome가 다시 실행되어
  저장하지 않은 내용과 커서 위치까지 그대로 돌아옵니다.
- **비정상 종료 복구**: 강제 종료·정전 뒤 다음 실행 때 저장하지 않은 문서를 복구할지 묻습니다.
- **여러 모니터**: 배율이 다른 모니터로 창을 옮겨도 창이 튀거나 깜빡이지 않고, 다음 실행 때 마지막 모니터·위치·크기로 엽니다.

## 빌드

사전 준비: Rust 툴체인(MSVC), Visual Studio 2022(C++ 데스크톱 워크로드, 리소스 컴파일러 rc.exe 포함).

```powershell
cargo run -- "C:\메모\할 일.txt"   # 개발 실행 (로그는 %LOCALAPPDATA%\mome\mome.log)
cargo test                         # 단위 테스트
cargo build --release              # 릴리스 빌드 -> target\release\mome.exe
```

> **Smart App Control이 켜져 있으면** cargo.exe와 직접 빌드한 exe가 모두 차단됩니다.
> Windows 보안 > 앱 및 브라우저 컨트롤 > Smart App Control 설정에서 끈 뒤 빌드하세요.

아이콘(`assets\icon.ico`, `assets\icon.png`)은 `scripts\make-icon.ps1`로 다시 만들 수 있습니다.

## 데이터 위치

| 내용 | 위치 |
|------|------|
| 설정 | `%APPDATA%\mome\settings.json` |
| 임시 저장 | 처음 실행할 때 선택한 폴더 (기본 `%LOCALAPPDATA%\mome\temp`) |
| 세션 기록(종료·복구용) | `%LOCALAPPDATA%\mome\sessions` |
| 로그 | `%LOCALAPPDATA%\mome\mome.log` |

임시 저장 폴더 구조:

```
<임시 저장 폴더>\
  메모.txt-1a2b3c4d5e6f7a8b\          문서마다 폴더 하나 (파일 경로로 정해짐)
    mome-doc.json                     원본 경로, 제목, 인코딩
    20261006-153012-123_auto.txt      버전마다 UTF-8 파일 하나 (덮어쓰지 않음)
    20261006-153522-456_save.txt
  untitled-20261006-150000-000-1234\  저장한 적 없는 문서
```

- 보관 기간 안의 버전은 하나도 지우지 않습니다. 보관 기간이 지난 버전만 1시간마다 정리합니다.
- 정리는 `mome-doc.json`이 있는 폴더 안의 버전 파일 이름 형식(`날짜-시각_종류.txt`)과 맞는 파일만 지우므로,
  다른 파일이 있는 폴더를 선택해도 안전합니다.
- 버전 종류: 자동, 직접 저장(지금 임시 저장), 파일 저장, 되돌리기 전, 다시 불러오기 전, 저장 안 함, Windows 종료

## Windows 종료 후 복원이 동작하는 방식

1. Windows가 종료·다시 시작·로그아웃을 시작하면 mome 창이 `WM_QUERYENDSESSION`(또는 `WM_ENDSESSION`)을 받습니다.
2. 저장하지 않은 내용을 임시 저장 폴더에 쓰고, 세션 기록(`sessions\<id>.json`)을 남긴 뒤
   `HKCU\...\CurrentVersion\RunOnce`에 `mome.exe --restore <id>`를 등록합니다.
3. 다음 로그인 때 Windows가 이 명령을 한 번 실행하고 지웁니다. mome는 세션 기록을 읽어 창을 되살립니다.

평소에 창을 닫을 때는 메모장처럼 저장 여부를 묻고, 세션 기록과 RunOnce 항목을 지웁니다.

## 구조

```
src/
├── main.rs        진입점, 명령줄(--restore, --revision), 아이콘
├── app/
│   ├── mod.rs     앱 상태, 프레임 루프, 열기/저장/닫기 흐름, 임시 저장 타이머, 세션 동기화
│   ├── commands.rs 명령·단축키 처리, 단축키 안내표
│   ├── editor.rs  egui TextEdit 래퍼 (겹쳐쓰기, 한글 IME 조합, 실행 취소 가능한 편집, 검색 강조)
│   ├── menu.rs    메뉴 모음, 오른쪽 클릭 메뉴, 다크 모드·편집/읽기·JSON 정리 버튼
│   ├── status.rs  상태 표시줄
│   ├── viewer.rs  읽기 모드 (Markdown 보기, 캔버스 그리기, 링크 열기)
│   ├── findbar.rs 찾기/바꾸기 표시줄 (옵션 단추, 제외, 바꿀 결과 미리보기)
│   ├── invisible_bar.rs 보이지 않는 문자 찾기 표시줄 (종류별 목록, 찾아가기, 정리)
│   ├── recovery.rs Windows 재시작 후 복원, 비정상 종료 복구, 버전을 새 창에서 열기
│   ├── dialogs.rs 대화상자 (저장 확인, 설정·최초 실행, 글꼴, 복구 등)
│   └── dialogs/history_browser.rs 임시 저장 기록 대화상자
├── document.rs    문서 모델 (경로, 인코딩, 줄 끝, 수정 여부), 안전한 파일 쓰기
├── encoding.rs    인코딩 감지·변환
├── history.rs     임시 저장 버전 저장소, 백그라운드 저장 스레드, 정리
├── session.rs     Windows 종료 감지(창 서브클래싱), 세션 기록, RunOnce, 비정상 종료 감지
├── placement.rs   창 위치 저장·복원(물리 픽셀), 배율이 다른 모니터로 옮길 때의 winit 버그 우회
├── print.rs       페이지 설정·인쇄 (Win32 인쇄 대화상자 + 숨긴 RichEdit로 쪽 나누기)
├── fonts.rs       Windows 글꼴 목록, egui 글꼴 구성 (한글은 맑은 고딕으로 대체·기준선 보정)
├── settings.rs    설정 파일
├── theme.rs       라이트/다크 색상, 해·달 아이콘
├── find.rs        찾기 (대/소문자, 단어 단위, 정규식), 그룹 참조·대소문자 바꾸기
├── stats.rs       줄·글자 수, 원고지 매수 계산
├── invisible.rs   보이지 않는 문자 분류·찾기·정리, 숨은 글자 풀기
├── json.rs        JSON 정리 (값은 글자 그대로 두고 들여쓰기만 다시 함)
├── markdown.rs    옵시디언 문법을 표준 Markdown으로 바꾸기, 링크·노트 찾기, 로컬 그림 읽기
├── canvas.rs      옵시디언 캔버스(JSON Canvas 1.0) 읽기, 연결선 위치·색
├── time.rs        현지 시각, 시간/날짜 넣기(F5)
├── win.rs         Win32 공통 도우미 (UTF-16 문자열, 창 서브클래스, 새 창 실행)
└── paths.rs, logging.rs
```

테스트용으로 `MOME_DATA_DIR` 환경 변수를 주면 설정·세션·로그를 그 폴더 하나에 모읍니다.
디버그 빌드에서는 `MOME_TEST_CMDS=History`(쉼표로 여러 개)처럼 주면 시작하자마자 그 명령을 실행하므로,
키보드·마우스 입력 없이 대화상자를 띄워 확인할 수 있습니다.
`MOME_TEST_DPI=96,144`를 주면 배율이 다른 모니터로 창을 끄는 상황을 흉내 내고 결과를 로그에 남깁니다
(모니터가 하나뿐일 때 확인용).

### 여러 모니터

- **배율이 다른 모니터로 옮길 때**: winit 0.30(eframe이 쓰는 창 라이브러리)은 Windows가 `WM_DPICHANGED`로 알려 준 창
  위치 대신 직접 계산한 위치를 쓰고, 끄는 중에는 창을 원래 모니터 쪽으로 되밀기도 합니다. 그러면 배율이 다시 바뀌고,
  이 과정이 반복되며 창이 튀고 깜빡입니다([winit#4600](https://github.com/rust-windowing/winit/issues/4600),
  [egui#7648](https://github.com/emilk/egui/issues/7648)). `placement.rs`는 창을 서브클래싱해, 최대화·최소화 상태가
  아니면 winit이 `SetWindowPos`를 부를 때 `WM_WINDOWPOSCHANGING`에서 위치를 Windows가 제안한 사각형으로 바꿔 줍니다
  (Microsoft 문서가 권하는 방식). winit이 이 문제를 고치면(PR #4694) 이 우회는 아무 일도 하지 않게 됩니다.
- **창 위치 기억**: egui 좌표(포인트)는 모니터 배율에 따라 크기가 달라서, 위치는 `GetWindowPlacement`의 물리 픽셀로
  저장하고 창이 보이기 전에 `SetWindowPlacement`로 되돌립니다. 그사이 해상도가 낮아졌거나 모니터를 뺐다면 남은 모니터의
  작업 영역 안으로 줄이고 옮깁니다.

## 패키징

```powershell
scripts\package.bat            # cargo build --release 후 dist\mome 폴더와 dist\mome-<버전>-win64.zip 생성
scripts\package.bat /nobuild   # 이미 빌드된 target\release\mome.exe 로 배포 폴더만 다시 구성
```

버전은 `Cargo.toml`의 `version` 하나로 정합니다. zip 파일 이름, `사용법.txt` 첫 줄, `mome.exe` 파일 속성(파일 버전),
`도움말 > mome 정보`에 모두 이 버전이 표시됩니다. 새로 배포할 때는 `version`을 올리고 아래 변경 내역에 적습니다.
