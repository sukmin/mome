mome (모메) 텍스트 편집기 {VERSION} - 사용법
==========================================

이 폴더의 구성
  mome.exe     편집기 본체 (단일 실행 파일, 설치 불필요)
  README.md    상세 설명 (기능, 단축키, 데이터 위치, 빌드 방법, 버전별 변경 내역)

  버전은 [도움말 > mome 정보]에서도 볼 수 있습니다.

바로 쓰기
  mome.exe를 실행합니다. 처음 실행하면 임시 저장 폴더를 선택하는 창이 열립니다.
  텍스트 파일을 mome.exe나 mome 창으로 끌어다 놓아도 열립니다.

임시 저장
  내용이 변경되었으면 10초마다(설정에서 변경 가능) 임시 저장 폴더에 새 버전을 하나씩 더 저장합니다.
  이전 버전은 덮어쓰지 않으며, [파일 > 임시 저장 기록](Ctrl+Shift+R)에서 되돌릴 수 있습니다.
  보관 기간(기본 30일)이 지난 버전만 자동으로 삭제합니다.
  저장하지 않고 닫아도 마지막 내용은 임시 저장 기록에 남습니다.

다크 모드
  메뉴 모음 오른쪽 끝의 달(또는 해) 버튼을 누르면 바로 바뀝니다.

상태 표시줄
  창 아래쪽에 줄/열, 글자 수(공백 포함), 200자 원고지 매수가 표시됩니다.
  원고지 매수는 줄이 바뀌면 남은 칸도 채운 것으로 센 대략적인 값입니다. 최종 분량은 한글(HWP) 문서 정보에서 확인하세요.

읽기 모드 (Markdown·옵시디언 캔버스)
  .md나 .canvas 파일을 열면 메뉴 모음 오른쪽에 [편집 | 읽기] 단추가 나타납니다(Ctrl+E).
  읽기 모드에서는 Markdown을 서식대로 보여 주고, [[노트]] 링크를 누르면 그 노트를 엽니다.
  (Ctrl+클릭하면 새 창에서 엽니다.) 옵시디언 캔버스는 끌어서 이동하고 Ctrl+휠로 확대/축소합니다.

찾기·바꾸기 (IntelliJ 방식)
  Ctrl+F로 찾고 Ctrl+R(또는 Ctrl+H)로 바꿉니다. 찾을 내용 옆의 단추로 방법을 고릅니다.
    Cc 대/소문자 구분(Alt+C)   W 단어 단위(Alt+O)   .* 정규식(Alt+X)
  정규식으로 바꿀 때는 $1, $2(그룹), ${이름}, \n(줄 바꿈)을 쓸 수 있고,
  \u, \l은 다음 한 글자를, \U … \E, \L … \E는 구간을 대문자/소문자로 바꿉니다.
    예: (\d{4})-(\d\d)-(\d\d) → $1년 $2월 $3일
  바꾸기(Alt+P), 모두 바꾸기(Alt+A), 제외(Alt+L: 이 항목은 바꾸지 않고 넘어가기)

보이지 않는 문자 찾기
  [편집 > 보이지 않는 문자 찾기](Ctrl+Shift+I)는 폭 없는 공백, 한글 채움 문자, 줄 바꿈 없는 공백처럼
  눈에 보이지 않는 문자를 종류별로 보여 주고, 하나씩 찾아가거나 한 번에 정리합니다(Ctrl+Z로 되돌리기).
  본문에는 분홍색으로 표시되며 [보기 > 보이지 않는 문자 표시]로 끌 수 있습니다.

Windows를 끌 때
  mome를 켜 둔 채 Windows를 끄거나 다시 시작하면, 다음 로그인 때 mome가 다시 열리고
  저장하지 않은 내용까지 그대로 돌아옵니다.

자주 쓰는 단축키
  Ctrl+N / Ctrl+Shift+N    새로 만들기 / 새 창
  Ctrl+O, Ctrl+S           열기, 저장
  Ctrl+F / Ctrl+R          찾기 / 바꾸기 (F3, Shift+F3으로 다음/이전, Ctrl+H도 바꾸기)
  Ctrl+G                   줄로 이동
  Ctrl+Shift+I             보이지 않는 문자 찾기
  Ctrl+E                   읽기 모드 / 편집 모드 (Markdown·캔버스)
  Insert                   삽입 / 겹쳐쓰기 전환 (상태 표시줄에 표시)
  Ctrl+더하기 / 빼기 / 0     확대 / 축소 / 기본 크기로 복원
  F1                       단축키 전체 보기

Smart App Control 안내
  Windows 11의 Smart App Control이 켜져 있으면 서명되지 않은 mome.exe 실행이 차단됩니다.
  [Windows 보안 > 앱 및 브라우저 컨트롤 > Smart App Control 설정]에서 끌 수 있습니다.
  (한 번 끄면 Windows를 다시 설치하기 전까지 다시 켤 수 없습니다.)
